# Biny Sebastian — Academic Portfolio

A fast, accessible, search-optimized static portfolio for GitHub Pages.

## Publish

Upload the contents of this folder to the root of the `binysebastian.github.io` repository and push to the default branch. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, and choose the repository root on the default branch.

## Search visibility checklist

1. Deploy the site and confirm `https://binysebastian.github.io/sitemap.xml` loads.
2. In Google Search Console, verify the existing property and submit that sitemap URL.
3. Request indexing for the homepage, research page, and publications page.
4. Keep Google Scholar, ORCID, STScI, LinkedIn, GitHub, and institutional profiles linked back to this exact homepage URL.
5. Update publications regularly. Search ranking and indexing can take days or weeks; metadata cannot guarantee placement.

No build step or framework is required. Open `index.html` locally to preview.
